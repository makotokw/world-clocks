# Chrome Web Store — Detailed description

Reference copy for the Chrome Web Store Developer Dashboard listing
("Store listing" > "Description" field for each published locale).
Not consumed by the extension build; kept here only as a source of truth
for the store listing text.

## en

```
World Clock — see the time in multiple cities at a glance.

Pin the extension icon to your toolbar, then click it to open a popup
showing analog clocks for the cities and time zones you choose.

Features:
• Add, remove, sort and edit clocks for any time zone
• Clean, canvas-based analog clock display
• Customize appearance and behavior from the options page

This extension uses coolclock (https://github.com/simonbaird/CoolClock) to
render the analog clocks.
```
